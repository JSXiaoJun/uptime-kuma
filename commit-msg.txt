fix: avoid :deep in Dashboard styles

The sidebar constraint used :deep(> .shadow-box), but this project's
stylelint config rejects both :deep (unknown pseudo-class) and ::v-deep
(unknown pseudo-element), and no other component in the codebase uses a deep
selector at all.

Passes a plain class to MonitorList (attrs merge onto its root element) and
constrains that class from a non-scoped style block instead.

Verified: npm run lint:style clean, eslint 0 errors, npm run build succeeds.
